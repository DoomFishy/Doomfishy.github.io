Memory Management Unit (MMU) Simulator

C | Page Tables | LRU | TLB | Demand Paging

The program simulates virtual address translation. It splits logical addresses into page numbers and offsets, then uses a TLB and page table to find the physical frame. On a page fault, it loads the missing 256-byte page from a backing store file into the physical memory using LRU replacement. It then computes the physical address, reads the signed byte value, and outputs the results with hit and fault rates to CSV files.

Key features implemented

  • Demand paging
  • LRU page replacement when memory is full
  • Page fault handling
  • Measuring TLB hit rate and page faults rate

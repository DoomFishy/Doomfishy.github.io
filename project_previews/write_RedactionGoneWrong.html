Redaction Gone Wrong

picoCTF | Forensics


Given a file containing a redacted document. Goal: recover the hidden information.


The black box appeared to be a drawn overlay rather than a true redaction. I hypothesized that the text was still present in the file's text layer, since redaction is often done by drawing a rectangle over the text—which removes nothing and only hides it visually.


I opened the PDF in a browser and used the element inspector over the black box area, looking for text behind the rectangle. The hidden text was present in the DOM and readable.


The recovered text contained the flag in the expected format. I also highlighted across the black box and copied it, and the pasted text matched. The two independent methods gave the same result.


Visual redaction is not data removal. Always verify where the underlying data actually resides rather than trusting the presentation layer.

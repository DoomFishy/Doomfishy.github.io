Multi-Agent AI

Python | Ollama | Gemma3 | Docker

A multi-agent AI system using Gemma3, Ollama, and Docker that processes user queries through a coordinated pipeline of master, validator, and compiler agents. It retrieves relevant content from PDF documents via ChromaDB semantic vector search, automatically falls back to real-time web searches when local knowledge is insufficient, and delivers validated, source-attributed responses with hit and fault tracking for performance analysis.

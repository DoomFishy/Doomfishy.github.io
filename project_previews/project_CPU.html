CPU Scheduling Simulator

C | FCFS | SJF | Round Robin | Priority | Hybrid Scheduling

The program implements a CPU scheduling simulator that reads task information from a file and runs 5 different scheduling algorithms.

  • First Come First Serve (FCFS)
  • Shortest Job First (SJF)
  • Round Robin (RR)
  • Priority
  • Hybrid: Priority and Round Robin for same priority tasks

Each scheduler tracks and outputs average waiting time, turnaround time, and response time.

Simple Steganography

Java Script | Python | ChaCha20 | Bit Manipulation

client-side image steganography web application that hides one image inside another using LSB encoding with password-based scrambling. Users upload a cover image and a secret image on the encode page, and the app embeds the secret image by replacing the lowest buts of each pixel's RGB values. A password based CSPRNG (CHACHA20) scrambles the embeding positions for security. The decode page extracts the hidden imager from a stego-image using the same password and LSB depth.
